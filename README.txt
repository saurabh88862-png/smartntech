SmartNTech - full website source code
=====================================

RUN THE WEBSITE ON ANY WINDOWS COMPUTER (nothing to install)
 1. Copy this zip to the computer and extract it (right-click > Extract All).
 2. Open the extracted "smartntech" folder.
 3. Double-click  START-WEBSITE.bat
    The website opens in the browser at  http://localhost:8780/
    Keep the black window open while you use the site. Close it to stop.
    (If Windows shows "Windows protected your PC", click More info > Run anyway.)

ADMIN LOGIN
 - Scroll to the bottom of the website and click  Admin  in the footer.
 - Log in with your admin email and password.
 - The dashboard shows visitors, site content, articles and contact messages.

IMPORTANT: WHERE THE DATA IS SAVED
 - Right now Firebase is not connected (FIREBASE_CONFIG = null in index.html).
   So visitor counts, edits and contact messages are saved ONLY in the browser
   of the computer you are using. Another computer starts with its own empty data.
 - To log in from ANY computer or phone and see the SAME data everywhere:
     a) put the site online (Netlify: drag the folder onto app.netlify.com/drop), and
     b) connect Firebase - follow FIREBASE_SETUP.md.

FOLDERS
 index.html          main website + admin dashboard
 assets/             logo, 3D effects (fx.css, fx.js), article renderer
 articles/           all articles, one file per category
 blog/               one page per article (generated by build.ps1)
 tools/, build.ps1   page builder: run build.ps1 after editing articles
 firebase.json, firestore.rules, FIREBASE_SETUP.md   Firebase setup
 sitemap.xml, robots.txt   for Google
